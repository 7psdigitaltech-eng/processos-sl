# C8 — HANDOFF COMERCIAL → OPERACIONAL

**Área:** Comercial / Operacional (processo de transição)
**Responsável:** Júlia ou Maria (preenche o briefing) → Pablo (executa a entrega)
**Quando usar:** Sempre que uma negociação for fechada por Eyder e o primeiro pedido for confirmado
**Tempo estimado:** 10–15 minutos para preencher o briefing

---

## O que é este processo

É a passagem formal de informações do time comercial para o time operacional no momento em que um novo cliente faz o primeiro pedido. Garante que Pablo tenha tudo que precisa para entregar sem precisar perguntar para Eyder ou para a vendedora.

## Quando iniciar

Imediatamente após Eyder confirmar o fechamento com o cliente e o primeiro pedido ser feito.

---

## Passo a passo

### PARTE 1 — PREENCHIMENTO DO BRIEFING (responsável: Júlia ou Maria)

**1. Abrir o formulário de Briefing de Novo Cliente**
- Usar o formulário padrão (planilha separada do Notion — ver aba "Briefing Operacional")
→ Ferramenta: Planilha de Briefing Operacional
→ Atenção: Não passar pedido para Pablo sem o briefing preenchido

**2. Preencher os dados obrigatórios do cliente**
- Nome completo da instituição
- CNPJ
- Endereço completo com complemento (rua, número, bairro, cidade, CEP)
→ Atenção: Verificar o endereço com o contato do hospital — não copiar do Google sem confirmar

**3. Preencher os dados de contato para entrega**
- Nome do responsável pelo recebimento de mercadoria
- Cargo do responsável
- Telefone direto para entrega
- WhatsApp para comunicação de entrega (se diferente do telefone)
→ Atenção: Este contato é quem vai receber o produto — pode ser diferente do nutricionista ou comprador com quem a venda foi feita

**4. Preencher os dados do pedido**
- Produtos pedidos (nome completo de cada produto)
- Quantidade de cada produto
- Data de entrega comprometida com o cliente
→ Atenção: A data comprometida é a que foi prometida ao cliente — Pablo precisa saber disso para priorizar

**5. Preencher condições comerciais**
- Forma de pagamento (boleto, pix, cartão, empenho)
- Prazo de pagamento combinado (à vista, 30 dias, 60 dias, outro)
→ Atenção: Nunca deixar essa informação em branco — impacta o financeiro

**6. Preencher observações especiais**
- Horário preferencial para entrega (ex: apenas manhã, não depois das 17h)
- Restrições de acesso (portaria com credencial, veículo específico, etc.)
- Necessidade de refrigeração no transporte (se aplicável)
- Qualquer outra informação que Pablo precise saber antes de ir

**7. Registrar documentação recebida**
- Marcar quais documentos foram recebidos: CNPJ ✓ / Comprovante de endereço ✓ / Outros
→ Atenção: Se algum documento estiver faltando, avisar Eyder antes de liberar o pedido

---

### PARTE 2 — PASSAGEM PARA OPERACIONAL (responsável: Júlia ou Maria)

**8. Enviar o briefing para Pablo**
- Compartilhar o link da linha preenchida na planilha pelo WhatsApp do grupo da empresa
- Mensagem padrão: *"Pablo, briefing do novo cliente [Nome do Hospital] preenchido. Primeiro pedido para entregar até [data]. Pode conferir?"*
→ Ferramenta: WhatsApp grupo da empresa + planilha de briefing
→ Atenção: Não enviar informações do pedido por mensagem avulsa — sempre apontar para a planilha

**9. Confirmar recebimento com Pablo**
- Aguardar Pablo confirmar que recebeu e leu o briefing
- Se não confirmar em até 2 horas: ligar diretamente
→ Atenção: Não assumir que Pablo viu — esperar confirmação explícita

---

### PARTE 3 — FOLLOW-UP PÓS-ENTREGA (responsável: quem fechou a venda — Júlia, Maria ou Eyder)

**10. D+1 após a entrega — Verificar se chegou tudo certo**
- Enviar WhatsApp para o responsável pelo recebimento
→ Modelo: *"Olá [Nome], tudo bem? A entrega chegou direitinho? Alguma observação?"*
→ Ferramenta: WhatsApp da empresa

**11. D+7 após a entrega — Verificar satisfação inicial**
- Enviar WhatsApp ou ligar brevemente
→ Modelo: *"Olá [Nome], passando para saber como estão os produtos. Alguma dúvida ou algo que posso ajudar?"*

**12. D+25 a D+30 — Antecipar próximo pedido**
- Entrar em contato antes do ciclo de compra do cliente
→ Modelo: *"Olá [Nome], o mês está terminando. Já posso preparar a cotação para o próximo pedido?"*
→ A partir daqui, o cliente entra no processo C7 (Gestão de Carteira e Recorrência)

---

## Como saber que terminou

O processo C8 termina quando:
- ✅ Briefing preenchido e confirmado por Pablo
- ✅ Entrega realizada e confirmada pelo cliente no D+1
- ✅ Cliente adicionado ao ciclo de carteira em C7

---

## Erros comuns

- **Passar o pedido para Pablo verbalmente ou por mensagem avulsa:** sem o briefing, Pablo pode entregar no endereço errado, no horário errado ou sem produto completo
- **Não confirmar o endereço com o cliente:** endereços de hospitais mudam de setor e de contato — sempre confirmar
- **Esquecer o follow-up D+1:** o cliente percebe quando ninguém liga depois da primeira entrega — é um diferencial da Santa Luzia
- **Deixar documentação incompleta:** pode travar o financeiro e atrasar futuras entregas

---

## Dúvidas frequentes

- **E se Pablo não estiver disponível quando o briefing for enviado?** → Registrar na planilha normalmente e avisar Eyder para acompanhar a confirmação.
- **E se o cliente mudar o endereço ou contato de última hora?** → Atualizar a planilha imediatamente e avisar Pablo por WhatsApp antes que saia para entrega.
- **Quem faz o follow-up D+1 se foi Eyder quem fechou a venda?** → Júlia ou Maria faz o follow-up. Eyder entra apenas se o cliente sinalizar algum problema.
- **O briefing de cliente recorrente (que já comprou antes) precisa ser preenchido de novo?** → Não. Apenas para o primeiro pedido de cada novo cliente. Para pedidos recorrentes, usar o processo C7.
